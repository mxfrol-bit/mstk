# МСТК — Технологии ясного зрения

Сайт: https://mstk-production.up.railway.app/

Railway публикует ветку main этого репозитория. Railpack обслуживает только каталог public; его расположение задано в Staticfile.

## Обновление

1. Установить зависимости: python3 -m pip install -r site-source/requirements.txt
2. Изменить шаблоны site-source/build.py, стили или изображения в site-source.
3. Собрать страницы: python3 site-source/build.py
4. Проверить результат, закоммитить исходники и public, отправить изменения в main.

Сборка содержит 15 основных страниц и 404. Старые адреса /envista.html и /products/iol.html перенаправляют к актуальным страницам. Данные продукции извлекаются из site-source/source-content.

Все девять изображений обновлены в стиле чистых предметных 3D-визуалов: нейтральный фон, новые объёмные ракурсы, компактный масштаб. Каталог использует горизонтальные карточки с изображениями шириной 96–160 px. Для семи линз и Stellaris использованы изображения производителя как референсы формы; эти иллюстрации не являются техническими чертежами. Для EYEFILL создан отдельный образ вискоэластичного материала без изображения упаковки. Источники перечислены в site-source/assets/product-images.json.

Форма подготавливает письмо на mstknn@gmail.com; посетитель отправляет его из своего почтового приложения.

На главной анимируется исходное изображение optical-hero.webp с прозрачной линзой и синим ободом. Анимация использует то же изображение как текстуру: небольшое покачивание, движение с параллаксом и мягкое изменение исходных бликов. Отдельная геометрическая модель линзы убрана. Есть пауза; настройка уменьшения движения оставляет исходное изображение неподвижным. Рендер останавливается вне экрана и в фоновой вкладке. При недоступном WebGL остаётся исходная картинка.

Three.js 0.169.0 включён локально в site-source/js/vendor; лицензия MIT находится рядом в THREE-LICENSE.txt. Внешний CDN для работы анимации не требуется. Модуль загружается только на страницах с крупными фотографиями. Изображение глаза получает параллакс, мягкое движение зрачка и световой проход по исходной радужке. Карточки и остальные изображения появляются при прокрутке и реагируют на наведение; их размер и файлы сохранены. Крупные сцены инициализируются по мере приближения к экрану; у каждой есть пауза.
